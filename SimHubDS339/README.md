# SimHubDS339

SimHub のテレメトリをダッシュボードとして描画し、DS339 (JONSBO 製サブディスプレイ) に **USB で直接** 表示する常駐ツールです。
ゲームを起動していないあいだは、CPU/GPU/メモリの使用率・温度などの PC ステータスを表示します。
AIDA64 や JONSBO 公式アプリは不要です。

> [!WARNING]
> 非公式ツールです。**使用は自己責任** でお願いします ([免責事項](../README.md#免責事項))。

```
SimHub → [Property Server plugin, TCP:18082] → SimHubDS339 (GDI+ で 960x376 描画) → libusb → DS339
```

## 前提

1. **SimHub Property Server プラグイン**: `PropertyServer.dll` (https://github.com/pre-martin/SimHubPropertyServer) を SimHub に導入し、有効にしておく (ポート 18082)。
2. **DS339 のドライバ**: インターフェース 3 (`MI_03`) を Zadig で WinUSB に置き換えておく (導入済み)。
3. **JONSBO-AIO / AIDA64 の DS339 出力は停止しておく**。同じデバイスを取り合うため同時には使えません。
4. **(任意) CPU 温度を表示する場合**: [PawnIO](https://pawnio.eu/) ドライバをインストールし、SimHubDS339 を **管理者として起動** する ([CPU 温度について](#cpu-温度について))。

## ビルドと実行

```bash
dotnet build -c Release
```

```bash
bin\Release\net8.0-windows\SimHubDS339.exe
```

| オプション | 内容 |
|---|---|
| (なし) | タスクトレイに常駐 |
| `--console` | 従来どおりコンソールウィンドウで常駐実行 (Ctrl+C で終了。デバッグ用) |
| `--fps N` | 送信レート (既定 10、1〜20。設定ファイルの値より優先) |
| `--stats SEC` | 統計ログの出力間隔 (既定 60 秒) |
| `--demo` | SimHub の代わりに擬似データでレース画面を表示 (実機の見た目確認用) |
| `--preview DIR` | デバイスに触れず、サンプル値で描画した PNG を DIR に出力して終了 |
| `--sensors` | PC ステータス用に検出したセンサーと現在値を一覧表示して終了 (値が `-` になるときの調査用) |

## 起動と終了

**起動**: SimHub と `SimHubDS339.exe` の両方を起動します (順番は自由)。`SimHubDS339.exe` をダブルクリックすると、タスクトレイにアイコンが表示されてバックグラウンドで常駐します (コンソールウィンドウは開きません)。SimHub やゲームが後から起動しても自動で接続します。

**終了**: タスクトレイアイコンを右クリック →「終了」をクリックします。常駐サービスが安全に停止し、USB 接続を閉じてから終了します。

**終了後の表示**: DS339 には最後の画面が静止したまま残ります。消したい場合は USB を抜き差ししてください。

**二重起動防止**: `SimHubDS339.exe` の二重起動は名前付き Mutex により自動で防止されます。JONSBO-AIO との併用はできません (DS339 を取り合います)。

**コンソールモード (`--console`)**: コマンドプロンプトからデバッグ等で実行したい場合は `--console` を指定します。Ctrl+C で USB を閉じて終了します。

## 設定とログ

タスクトレイアイコンのダブルクリック、または右クリック →「設定...」から設定ウィンドウを開くことができます。

- **起動設定**: Windows 起動時の自動起動モード (しない / 通常権限 / 管理者権限)
- **表示設定**: 送信フレームレート (FPS, 1〜20)
- **SimHub 接続設定**: Property Server のホストとポート (既定: 127.0.0.1:18082)

設定ファイルとログファイルは以下の場所に保存されます。

- **設定ファイル**: `%APPDATA%\SimHubDS339\settings.json`
- **ログファイル**: `%LOCALAPPDATA%\SimHubDS339\SimHubDS339.log` (トレイメニューの「ログを開く」から既定のエディタで開けます。サイズが 1MB を超えると起動時に自動で `.old.log` にリネーム・ローテーションされます)

### 自動起動

設定ウィンドウ (トレイメニュー →「設定...」) から、Windows 起動時の自動起動を設定できます。

- **自動起動しない**: 自動起動の登録を解除します。
- **Windows 起動時に起動する**: 現在のユーザーのレジストリ (`HKCU\Software\Microsoft\Windows\CurrentVersion\Run`) に `SimHubDS339` を登録し、通常権限で自動起動します。
- **Windows 起動時に管理者として起動する (CPU 温度を表示する場合)**: Windows タスク スケジューラにタスク `SimHubDS339` を最上位の特権 (`HighestAvailable`) で登録し、ログオン時に管理者権限で自動起動します (設定時に UAC の確認が表示されます)。

どちらも `SimHubDS339.exe` のフルパスを登録します。exe を別のフォルダに移動した場合は、設定ウィンドウで自動起動を設定し直してください。

## 画面

- **PC ステータス画面** (SimHub 未接続、またはゲーム未起動): 時計・日付・SimHub の接続状態、CPU (使用率・温度・クロック)、GPU (使用率・温度・VRAM)、メモリ (使用率・使用量)、直近 60 秒の使用率グラフ、ネットワークの送受信速度
- **レース画面** (`dcp.GameRunning` が True): シフトライト、ギア、速度、RPM バー、ラップ/順位、現在・前回・ベストのラップタイム、スロットル/ブレーキ、燃料

レイアウトは `DashboardRenderer.cs` で変更できます。`--preview` で PNG を出してから確認すると手早く調整できます。

PC ステータスは [LibreHardwareMonitorLib](https://github.com/LibreHardwareMonitor/LibreHardwareMonitor) で 1 秒ごとに取得します。レース画面の表示中は取得を止め、ゲームの負荷を増やさないようにしています。GPU は内蔵 GPU より単体 GPU を優先して表示します。

### CPU 温度について

CPU の温度は、CPU のレジスタを読むためにカーネルドライバ **PawnIO** と **管理者権限** の両方が必要です。どちらかが欠けていると `-°C` と表示され、画面右下に案内が出ます。CPU 使用率・クロック・GPU・メモリ・ネットワークは、通常権限でもドライバなしでも表示されます (クロックは PawnIO がない場合、タスク マネージャーの「速度」と同じ方法で求めた実効クロックを表示します)。

1. https://pawnio.eu/ から PawnIO をインストールする
2. トレイメニューの「管理者として再起動 (CPU 温度を表示)」をクリックする、または設定ウィンドウで「Windows 起動時に管理者として起動する」を選択する

## 動作の仕組み (DS339 プロトコルの要点)

実装は `..\DS339Direct\Ms9132Device.cs` を共有しています。実機キャプチャと実機テストで判明した仕様は次のとおりです。

- フレームは 376x960 (チップ上の向き)。パネルは横置きのため、見た目 960x376 の画像を時計回りに 90 度回転して送る
- Bulk OUT (ep 4) に `8 バイトヘッダ + 画素 + 8 バイトトレイラ` を 65536 バイトずつ送り、最後にゼロ長パケットを送る
  - ヘッダ: `FF, x(16bit), y(16bit), 幅(12bit)|高さ(12bit)`、全画面なら `FF 00 00 00 00 17 83 C0`
  - トレイラ: `FF C0 00 00 00 00 00 00`
- 画素のバイト順は B,G,R
- **画素データに 0xFF を含めてはならない** (マーカー扱いされ、転送が極端に遅くなり表示が乱れる)。255 は 254 に丸める
- 公式アプリ同様、xdata `0x0032` を 500ms 周期で読むハートビートを行う
- 送信失敗や USB エラー時は 3 秒後に自動で再接続・再初期化する

## 元に戻す

1. 設定ウィンドウで「自動起動しない」を選択して保存し、自動起動の登録を解除してからアプリケーションを削除してください。
2. JONSBO-AIO に戻す場合は、Zadig でインターフェース 3 のドライバを `libusb-win32` (または元のドライバ) に戻してください。
